# Pola Wyboru - GASSU Product Configurator\n\nAdvanced WooCommerce product configurator plugin for GASSU shoes with dynamic heel height switching, customizable options, and persistent configuration management.\n\n## Table of Contents\n\n- [Features](#features)\n- [Requirements](#requirements)\n- [Installation](#installation)\n- [Configuration](#configuration)\n- [Usage](#usage)\n- [Architecture](#architecture)\n- [API Reference](#api-reference)\n- [Hooks & Filters](#hooks--filters)\n- [Troubleshooting](#troubleshooting)\n- [Contributing](#contributing)\n\n## Features\n\n### 1. Sole Type Selection\n\nCustomers can choose between:\n- **Velvet (Welur)** - soft velvet sole\n- **Leather (Skóra)** - genuine leather sole\n\nThis selection is saved as order item metadata and persists when changing heel height.\n\n### 2. Dynamic Heel Height Switching\n\n- Products are organized by model, color variant, and heel height\n- Each heel height is a separate product with its own URL and SKU\n- Changing heel height redirects to the corresponding product\n- Products are matched by:\n  - `pa_model` - product model attribute\n  - `pa_wersja_kolorystyczna` - color variant attribute\n  - `pa_wysokosc_obcasa` - heel height attribute\n\n### 3. Customizable Heel Height Display Names\n\nAdministrators can configure customer-facing display names for each heel height:\n- Technical value: `8 cm`\n- Customer display: `7.5-8.5 cm` (size-dependent)\n\nConfigurable through WooCommerce admin panel under **WooCommerce > GASSU Configurator**.\n\n### 4. Shoe Width Selection\n\nCustomers can choose shoe width with standard as default:\n- **Narrow (Wąska)**\n- **Standard (Standardowa)** - *default*\n- **Wide (Szeroka)**\n\nSelection is saved as order item metadata.\n\n### 5. Toe Cushion Options\n\nCustomers can select:\n- **Foam (Pianka)** - additional soft foam cushion\n- **Hard (Twardo)** - no additional cushion\n\nSelection is saved as order item metadata.\n\n### 6. Custom Colorimetry\n\n- Optional checkbox to request custom color\n- Opens textarea for detailed color requirements\n- Saved as order item metadata\n- Persists across heel height changes\n\n### 7. Custom Size Requests\n\n- Optional checkbox for unusual size orders\n- Opens textarea for size specifications\n- Includes link to `/tabela-rozmiarow/` (foot measurement chart)\n- Saved as order item metadata\n- Persists across heel height changes\n\n### 8. Configuration Persistence\n\nAll configuration selections are preserved when changing heel height:\n- Stored in WooCommerce session\n- Automatically restored when navigating to new product\n- Prevents losing customer selections during product switching\n\n### 9. Shortcode\n\nEmbed configurator on product page:\n\n```\n[gassu_product_configurator]\n```\n\nAutomatically detects current product and:\n- Identifies model and color variant\n- Retrieves available heel heights\n- Displays configuration options\n- Handles heel height switching\n\n## Requirements\n\n- WordPress 5.0+\n- WooCommerce 3.0+\n- PHP 7.2+\n- jQuery (loaded by WooCommerce)\n\n## Installation\n\n1. Upload the plugin to `/wp-content/plugins/pola-wyboru/`\n2. Activate the plugin through **Plugins** menu in WordPress admin\n3. Ensure WooCommerce is installed and activated\n4. Plugin automatically initializes on `plugins_loaded` hook\n\n## Configuration\n\n### Admin Panel\n\nAccess settings at: **WooCommerce > GASSU Configurator**\n\n#### Heel Height Display Names\n\n1. Navigate to **WooCommerce > GASSU Configurator Settings**\n2. You'll see a table with all available heel heights from your product attributes\n3. Enter custom display names for each heel height\n4. Click **Save Changes**\n\nThe plugin automatically discovers all `pa_wysokosc_obcasa` terms and creates input fields for each.\n\n### Product Setup\n\nFor configurator to work, products must have:\n\n1. **Model attribute** (`pa_model`)\n   - Example: \"Paula\", \"Sandra\", \"Gabriela\"\n\n2. **Color variant attribute** (`pa_wersja_kolorystyczna`)\n   - Example: \"red-colorful\", \"black-classic\"\n\n3. **Heel height attribute** (`pa_wysokosc_obcasa`)\n   - Example: \"8 cm\", \"10 cm\", \"5.5 cm\"\n\n4. **Published status** - Only published products appear in configurator\n\n5. **Grouping** - Products with same model + color variant form a group\n\n#### Example Product Structure\n\n```\nProduct 1:\n- Title: Paula 8 cm – Colorful Sandals\n- SKU: paula-colorful-8cm\n- Model: Paula\n- Color Variant: red-colorful\n- Heel Height: 8 cm\n- Status: Published\n\nProduct 2:\n- Title: Paula 10 cm – Colorful Sandals\n- SKU: paula-colorful-10cm\n- Model: Paula\n- Color Variant: red-colorful\n- Heel Height: 10 cm\n- Status: Published\n```\n\n## Usage\n\n### For Store Managers\n\n1. **Create products** with proper attributes (Model, Color Variant, Heel Height)\n2. **Configure heel display names** in plugin settings\n3. **Add shortcode** to product description or custom section:\n   ```\n   [gassu_product_configurator]\n   ```\n4. **Monitor orders** - Configuration data appears in order details\n\n### For Customers\n\n1. **Select heel height** - Choose from available heights for current model/color\n2. **Choose sole type** - Velvet or Leather\n3. **Set shoe width** - Narrow, Standard, or Wide\n4. **Select toe cushion** - Foam or Hard\n5. **Add custom options** (optional):\n   - Check \"Custom Color\" and describe requirements\n   - Check \"Custom Size\" and specify measurements\n6. **View configuration in cart** - All selections displayed\n7. **Change heel height** - All options preserved automatically\n\n### Order Integration\n\nAll configuration appears in:\n- **Cart page** - itemized with product\n- **Checkout page** - order summary\n- **Order confirmation email** - customer notification\n- **Admin order page** - order management\n- **Customer account page** - order history\n\n## Architecture\n\n### Plugin Structure\n\n```\npola_wyboru/\n├── pola_wyboru.php                 # Main plugin file\n├── includes/\n│   ├── Pola_Wyboru_Order_Integration\n- Hooks into WooCommerce cart/checkout\n- Adds configuration to cart items\n- Displays configuration data in cart\n- Saves configuration as order item metadata\n\n#### Pola_Wyboru_Admin\n- Admin initialization\n- Registers admin menu\n- Instantiates settings page\n\n#### Pola_Wyboru_Admin_Settings\n- Renders settings page\n- Discovers heel height terms\n- Manages change via AJAX\n- Saves configuration to session\n- Returns target product URL\n\n## API Reference\n\n### Product Mapper\n\n```php\n// Get all products in same model/color group\n$products = appearing\n\n1. **Check WooCommerce is activated** - Plugin requires WooCommerce\n2. **Verify shortcode is added** - `[gassu_product_configurator]` must be on page\n3. **Check product attributes**:\n   - Product must have `pa_model` attribute\n   - Product must have `pa_wersja_kolorystyczna` attribute\n   - At least one other product with same model/color must exist\n4. **Verify product is published** - Only published products appear\n\n### Configuration not persisting\n\n1. **Check WooCommerce session** - Session must be initialized\n2. **Verify browser cookies** - Session ID stored in cookies\n3. **Check PHP session settings** - May need to configure in `php.ini`\n4. **Review browser console** - JavaScript errors may prevent AJAX\n\n### Heel height change not working\n\n1. **Check AJAX URL** - Verify `admin-ajax.php` is accessible\n2. **Check browser console** - Look for JavaScript errors\n3. **Verify product exists** - Target product with new heel height must be published\n4. **Check nonce** - Security verification may be failing\n\n### Display names not updating\n\n1. **Clear browser cache** - Cached configuration options\n2. **Verify database permissions** - Settings must be saveable\n3. **Check user capabilities** - Must be admin to modify settings\n4. **Inspect options table** - Check `pola_wyboru_heel_display_names` option\n\n## Development\n\n### Adding Custom
